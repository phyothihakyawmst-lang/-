📖 What is a Circular Queue?

A Circular Queue is an extended version of a normal Queue. When the Rear pointer reaches the end of the array, it wraps around to the beginning (Index 0) if there is empty space available. This solves the major memory waste problem of a normal queue, allowing continuous reuse of empty slots without needing to shift elements or clear the array repeatedly!
